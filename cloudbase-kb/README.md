# 把「高性价比人生指南」接到腾讯云 CloudBase 智能体 / 工作流

本目录是给**腾讯云 CloudBase 智能体（Agent）+ 知识库**准备的导入素材与接入说明。
目标：把现有小程序/网页的 AI 问答，从「自己写的端侧 top5 检索 + HY3 代理」升级为「CloudBase 知识库托管检索 + 智能体回答」，平台自动做 RAG 和引用，前端只改调接口。

## 1. 知识库上传素材（已就绪）

- `高性价比人生指南_全量.md` —— 669 条建议合并成一个文件，含「一句话 / 成本 / 收益证据 / 来源 / 备注 / 标签 / 证据等级」全部字段，最适合一次性导入。
- `chapters/` —— 34 个分章 markdown（原始干净版），想按章管理或分批导入时用。

> 任选其一上传即可。全文单文件检索召回更稳，分章文件便于按需维护。

## 2. 在 CloudBase 控制台创建智能体（步骤）

1. 进入 **云开发 CloudBase 控制台 → AI（智能体）**，新建一个**智能体**。
2. 进入智能体的**知识库**，点击「导入」，上传上面的 `高性价比人生指南_全量.md`（或 `chapters/`）。等待索引完成（平台会自动切片 + 向量化）。
3. 在智能体配置里**绑定这个知识库**，并设置检索策略（建议：向量检索 + 关键词混合，召回 5~8 条）。
4. 填写**人设 / 提示词**（见下方「推荐提示词」）。
5. **发布**智能体，控制台会给出它的**对话 API 地址**和鉴权方式（通常在同一个 CloudBase AI 网关上，OpenAI 兼容格式，和我们已在用的 `…/v1/ai/cloudbase/chat/completions` 同源）。

## 3. 推荐提示词（人设）

```
你是「高性价比人生指南」的 AI 助手。你的全部知识来自已接入的知识库（改编自公开出版的《How To Live Better》中译整理版，共 34 章 669 条基于证据的生活建议）。

回答规则：
1. 只依据知识库内容作答，不要编造具体数据、年份或出处。
2. 用简洁、可操作的中文回答；涉及健康/法律/财务时，提醒用户这是通用建议、严重情况请咨询专业人士。
3. 每条关键结论后，用「参考：第X章《章节名》· 条目标题」标注出处（与知识库里的章节/条目对应）。
4. 如果知识库不足以回答，如实说明，并给出谨慎的常识性建议。
```

## 4. 前端怎么改接（沿用现有小程序/网页）

核心变化：**检索交给平台，前端不再自己算 top5**（也可保留做预筛选以省 token，二选一）。

- 现有 `tencent-hy3-proxy/server.js` 默认转发到 `…/v1/ai/cloudbase/chat/completions`（模型 `hy3`）。
- 智能体发布后，把代理的 `HY3_API_URL` 改成**控制台给出的智能体对话地址**，必要时用 `HY3_API_KEY` 换成智能体对应的密钥；请求体保持 `model` + `messages` + `stream:true`（OpenAI 兼容，前端 `askViaProxy` / 预览 `askAI` 不用改）。
- 小程序 `app/utils/ai-config.js` 的 `proxyUrl`、预览 `preview-template.html` 顶部的 `AI_PROXY_URL` 保持指向你的代理即可，**密钥仍在你服务端，绝不进前端**。

> 我可以根据你拿到的真实智能体 endpoint / key 变量名，直接帮你改 `tencent-hy3-proxy/server.js` 的默认值和环境变量名。把控制台给出的调用信息发我就行。

## 5. 与现在的区别（为什么值得接）

| 现在（手写） | 接 CloudBase 智能体后 |
|---|---|
| 端侧 top5 检索（关键词匹配） | 平台向量 RAG（语义检索，召回更准） |
| 自己拼上下文、自己控引用 | 平台自动检索 + 自动标注出处 |
| 要自己维护代理与重试 | 平台托管，只需换 endpoint |
| 模型固定 hy3 | 智能体内可切换/编排多模型与工作流 |

密钥安全边界不变：**JWT/密钥只在你服务端代理的环境变量里，前端永不接触。**
