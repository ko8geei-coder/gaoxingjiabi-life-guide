# 高性价比人生指南 · 微信小程序（演示版）

把 GitHub 上爆火的 **《高性价比人生指南》**（[eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)，13k+ star）做成了一个离线可看的微信小程序阅读器。

> 内容 100% 来自原仓库 `book/` 目录的 34 章 markdown，已解析为结构化数据（每条建议含：标题、花费/回报标签、说人话、成本、收益证据、证据等级、来源、备注）。**仅用于学习演示，版权归原作者所有。**

## 工程结构
```
life-guide/
├── download.js        # 拉取原仓库 34 章 markdown
├── parse.js           # 把 markdown 解析为 data/guide.json（669 条建议）
├── data/
│   ├── raw/           # 原始 .md 文件
│   └── guide.json      # 结构化数据（0.8MB）
└── app/               # 微信小程序工程
    ├── app.js / app.json / app.wxss
    ├── data/guide.json
    ├── images/tabbar/  # 6 个图标（纯 Python 生成，无外网）
    └── pages/
        ├── index/      首页：搜索 + 今日一条 + 章节网格
        ├── chapter/    章节页：单章列表 / 搜索结果
        ├── detail/     详情页：单条建议全文 + 收藏
        └── mine/       我的：收藏、历史、随机、关于
```

## 功能
- 🔍 **搜索**：跨 669 条建议搜关键词（保险/租房/裁员…）
- 🎲 **今日一条 / 随机一条**：随机抽一条，配证据等级
- 📚 **34 个主题章节**：不要早死、不要浪费钱、租房买房、恋爱结婚、创业、紧急情况、看病、出国留学…
- 📖 **详情页**：花费(钱/时间/毅力) + 回报 + 说人话 + 收益证据 + 备注 + 来源（可复制）
- ⭐ **收藏 / 浏览历史**（本地持久化，无需后端）

## 怎么跑起来
1. 安装**微信开发者工具**。
2. 导入项目 → 选择本目录下的 `app/` 子目录。
3. AppID 选「测试号 / 游客模式」（`project.config.json` 已设为 `touristappid`）。
4. 编译即可在模拟器里浏览全部 669 条建议。
